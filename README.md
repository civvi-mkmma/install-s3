## Page 1/3

### Étape 1 : Alimenter le module ESP8266
* (Illustration : Brancher le module ESP à l'aide d'un câble USB vers un chargeur)

### Étape 2 : Se connecter au réseau Wi-Fi
* Ouvrez les paramètres de votre appareil.
* Accédez au menu **Wi-Fi**.
* Connectez-vous au réseau : `> civvi-XXXX`

---

## Page 2/3

### Étape 3 : Ouvrir le portail (Écran "0")
* Ouvrez un navigateur web sur votre appareil.
* Saisissez l'adresse IP : `192.168.4.1`
* Cliquez sur le bouton **ACCEDER** sous le logo CIVVI.

### Étape 4 : Interface principale (Écran "1")
Structure de l'interface principale :
* **1.5** Info Réseau (Barre d'en-tête)
* **1.6** Mon Message (Barre de pensée)
* **1.7** Lignes Voisins (Blocs centraux)
* **1.9** Rédaction & **1.10** Tris (Barre de contrôle)

*Les 4 coins de l'écran sont équipés de boutons de couleur (voir étape 5).*

---

## Page 3/3

### Étape 5 : Navigation (Les 4 Coins)
* **[1.1] Bleu / Rond (En haut à gauche) :**  
  Accès à l'Écran 2 (Profil & Avatar)
* **[1.2] Jaune / Segment (En haut à droite) :**  
  Accès à l'Écran 3 (Messagerie personnelle)
* **[1.3] Rouge / Triangle (En bas à gauche) :**  
  Accès à l'Écran 4 (Configuration & Modes)
* **[1.4] Violet / Carré (En bas à droite) :**  
  Accès à l'Écran 5 (Chaine Humaine)

### Étape 6 : Détails d'une ligne (1.7)
Composition d'une ligne voisin :
* **1.7.1** 👕 (Profil/Vêtement)
* **1.7.2** 📄 (Document)
* **1.7.3** Nom
* **1.7.4** Message...
* **1.7.5** ✔️ (Émoticône / Validation)
* **1.7.7** ✉️ (Lettre / Envoi)
